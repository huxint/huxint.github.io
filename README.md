# huxint's blog

个人博客源码。纯静态 HTML / CSS / JS，无构建。

## 本地预览

    python3 -m http.server 8000

然后访问 http://localhost:8000

## 部署

push 到 `main` 分支会触发 GitHub Actions 自动部署到 GitHub Pages。
