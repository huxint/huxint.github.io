Vibe 两年 · 心流消散记

Cursor → Trae → Codex → DeepSeek tab → agent → skills yes → bypass permission
2026 / 05 / 24 · 12 min read · AI Vibe Coding 杂谈

2023 年起 AI 大爆发，这几年各种模型一路用下来，我确实感觉到 —— 自己独立思考的能力已经大不如前。这篇就梳理一下，我两年的 AI 使用史，以及它顺手带走的东西。

第一次：Cursor 与那只蛔虫

我是 2024 年末第一次接触 AI agent 编程。在那之前，跟大家一样，最多在网页里简单问答几句。

第一次用 cursor 的感觉是 —— 哇塞，怎么能这么好用。说实话，那时候 cursor 的 agent 能力没怎么震到我，反倒是它的 tab 补齐，简直就是我肚子里的蛔虫 —— 我还没开始打，它就把我心里想的代码给补出来了。

那段时间我有一门微信小程序的课，花了一个月左右，靠 claude sonnet 3.5 把前后端和数据库都搭起来了。其实前后端很快就能搭好，主要是我代码洁癖太重，想一次性写到位、设计到位，反复改了又改。那时候我从没看过数据库原理，没手搓过数据库，只知道它"大概能干嘛"。从那以后，我就迷上了 vibe coding。

期待 Claude 的日子

之后每次 claude 出新模型，我都特别期待。在我心里 claude 一直是最好的编程模型 —— sonnet 3.7 那阵写出来的工程代码，相当优雅。

不过复杂的数学推理和逻辑分析，最牛的还得是 GPT 的 o1，独一档。GPT 的命名……唉，4o、o4、o3，混乱得离谱 —— 而且 o4 还比 o3 拉很多，光看名字根本对不上能力档位。

DeepSeek R1 · 一个让我惊艳的名字

25 年初 DeepSeek R1 出来，能力很强，竟然还把模型的 CoT 摊开给你看。

第一次看到 "DeepSeek" 这个名字，我心里只剩一句：卧槽，取得也太好了。这种感觉跟 "字节跳动" 给我的感觉一样 —— 让我觉得取名也是一门艺术。

也正因如此，我那时一直想不通：怎么会有公司把模型取名叫 豆包？没少跟朋友吐槽。

不过现在我想法变了。豆包名字独特，走大众路线，迎合个人情感需求，是个不错的陪伴助手 —— 虽然有时候很弱智，但它符合大众口味。话说回来，豆包现在也有深度思考模式，有 doubao code，整体能力其实挺强。

中段比较模糊：Cursor 退场，Claude Code 登场

后面的事情有点模糊。只记得 claude 每次发新模型我都十分期待 —— 毕竟马上就能在 cursor 里体验上。那阵子 cursor 封号不算严重，无限账号插件满天飞，体验拉满。

后来 cursor 的无限账号插件也只剩廉价模型和 auto 模式能用，我就转向了 augment。那是一个非常强的 agent 插件，我个人甚至觉得是当时最好用的；只是后来它各种封号、价格也越来越贵，连无限插件都救不回来 —— 自此就很久没碰过了。

再后来就第一次摸到 claude code。它好像是第一款把 IDE 和插件解耦的 —— 只要有个终端，就能到处 vibe coding。

25 秋：Trae · Kiro · Windsurf 大乱斗

25 年 9 月左右开始用 trae。当时市面上已经有一堆 AI IDE：kiro、windsurf、cursor……

cursor 我已经久不碰了，封号太严，就算用也只剩 auto 模式，我不喜欢黑盒，弃。windsurf 体验下来一般 —— 除了能薅模型，其他都拉。kiro 倒是第一次让我接触到「规范文档编程」：写代码前先让 AI 写一份规划文档。

后来主要用 trae。它说不上多牛逼，但 免费。各种国产模型随便挑，一路用下来 —— glm5、kimi k2.5、minimax 2.5，应付学校作业绰绰有余。但 minimax 我一直觉得不行，实测也确实如此，到现在 minimax 2.7 还是得坐在小狗那一桌。

trae 的 solo 模式我几乎没用过 —— 当时要邀请链接，我又不太好意思求人，就一直拖着没上。等现在不要邀请码了，我好像也用不上了。

国内模型的纠结

glm 算是国内编程的一把好手。我能用上它，多半也得靠 trae 中转。后来 glm 5.1 出来确实牛逼，但我既没钱买套餐，trae 又得排队。

kimi k2.5 也牛逼，multi agent 很强，但我也就充过 10 块钱体验一下。

Codex 让我意外

25 年 10 月，codex 这边开始起势 —— 9 月 GPT-5-Codex 上 API，10 月才真正铺开。说实话当时我看不太上它，以为又是个 vscode 插件壳子，连 GPT-5 也没怎么碰。

但用完之后真出乎我意料：codex 给我的感觉像一个特别严谨的工程师 —— 逻辑思维断档领先，代码极其优雅。最戳我的，是它写 Python 永远用尾置类型声明：

def add(a: int, b: int) -> int:
    ...

x: int = 10

雅，太雅了 —— 正中我的代码审美。反观 claude 就不爱写，虽然我不会明说 🌚。

Claude 这条线，没断过

说回 claude，这条线我从头到尾几乎没断过 —— sonnet 一路从 3.5、3.7、4、4.5 到 4.6；opus 那条从 4 起步，一路 4.1、4.5、4.6、4.7。新版一发，我基本都第一时间去碰一下。

后来又出了那个被传得神乎其神的 "mythos" —— 强到 anthropic 自己都不敢公开放出来，只通过 Project Glasswing 给少数合作伙伴用。我到现在都不太分得清是它真的恐怖，还是 anthropic 自己营销玩得好。

顺便吐槽一下 anthropic，真的很无语：各种反华操作不断 —— 不知道情况的人还以为中国人对它做了啥。

26 年的牌桌

26 年这一年的新模型，我对国内的关注少了 —— 除了 glm 和 kimi，其他真不太行。GPT 5.3 codex、5.4 发布那阵是 GPT 最泛滥的时候，根本不愁 token。现在也凉了，封号潮卷土重来。

26 年初我一直盼着 DeepSeek 能复刻 25 年的奇迹，再让我们用上量大管饱的 token。它没来。

龙虾、Open Claw 与生态破壳

26 年 2 – 4 月龙虾爆火，各种各样的人开始"养龙虾"。我用过 open claw，纯属屎山代码堆砌，但它确实把大众从 GUI 推到了 CLI，也逼着各家不得不开放 agent 接口 —— 这种倒逼，反过来促成了 agent 生态的发展。

DeepSeek V4 Pro：终于回来了

4 月末 GPT 5.5 发布，体感提升其实不大。没想到当天 DeepSeek V4 Pro 居然也发了 —— 几乎前后脚，两边一起摔到牌桌上。看价格，emmm……比国外的便宜很多。能力跟 glm 5.1 相当，稍逊一点，但思维逻辑在国内是第一档。

我这种没钱的本来还是舍不得充。可它打折了啊，那就不一样了。现在折扣还变成了永久，但大家好像早就猜到会是这个结局。梁圣还是牛逼。

其实光看输入输出价格也就那样，真正的杀手锏是 DeepSeek 的缓存，让综合成本更低。

现在的局面就是 —— 比 DeepSeek 拉的、又没 DeepSeek 便宜的，可以直接抬走了。

从 Tab 到 Skills

从 tab 补全 → agent 调用工具编程 → 各种规范编程的玩法，从 rules → memory → mcp → skills，我算是完整感受到了：agent 编程确实是个大趋势。

（对我来说 rag 没用 —— 我没什么个人知识库，而且我觉得未来 rag 应该会被淘汰？maybe。）

但即便这样，目前 AI 还是被局限在某个圈子范围里，总像缺了一点真正的突破。

心流去哪了

我越来越觉得，vibe coding 没让我找回以前那种沉浸式编程的心流。

从前 / past

古法编程

一坐就是一整天，闷头敲代码进入心流。脑子和手是连着的。

现在 / now

Vibe Coding

全程 yes，玩一会儿手机；yes，玩一会儿手机；yes，玩一会儿手机 ……

后来连 yes 都懒得按，直接 --dangerously-skip-permissions。再后来 goal 一下直接上床休息，远程查看就行。

他们管以前那种叫 古法编程，但我和 AI 一起进入心流的状态确实越来越少 —— 剩下的更多是「吸食 token」带来的快感。这种感觉很怪：只要有高级 token，我就能和 AI 通宵；甚至会开始 看不起廉价 token。

一个让我反复想的问题

a quiet thought / 关于意识

都说模型不会拥有智能和意识。我是人工智能专业的，对模型原理多少算清楚一点点，也相信目前的模型并不会产生意识。

但现在的参数量都是 T 级别的。这种参数量真的不会涌现出智能吗？我越来越疑惑这个问题。如果现在没有 —— 未来呢？

我变成了什么样

用 AI 的这个过程里，我越来越不爱思考，越来越习惯快节奏的东西。碰到问题就丢给 AI，慢慢变成一种"AI 能做的我就能做，AI 做不到的我就不会"的状态。

代码洁癖那块倒一直没改：我不想让 AI 写出垃圾代码，要求它符合各种设计模式、保持简洁优雅、modern。这反而让一件事难以一次完成，各种细节 fix 和 review 不断。

但过度依赖 AI 的代价是肉眼可见的 —— 思考能力在变差，注意力越来越散，三分钟热度又漏气。

写在最后

其实这篇更多是分享我用 vibe coding 的这条线、我视角里的 AI 发展史，以及在 AI 这个时间点 —— 我们到底该怎么继续保持自己的思考，怎么留住那点独有的创造力和对事情的见解。

可以看到，我连这段话都写得不算利索。这是我表达能力的局限，也是自己 CoT 还不够 —— 没组织好表达框架的逻辑。

但起码我自己写了。
